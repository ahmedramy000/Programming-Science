===========================================================
 علوم البرمجة — تعليمات الرفع (الباك إند + الفرونت إند)
===========================================================

ملخص سريع: المشروع فيه 3 فولدرات
  backend/   -> سيرفر Node.js/Express (فيه API + نظام تسجيل الدخول)
  frontend/  -> كل صفحات الموقع (HTML/CSS/JS) - الكتاب + التفاعلي
  database/  -> schema.sql (بنية قاعدة بيانات PostgreSQL للمستقبل)

-----------------------------------------------------------
1) أسهل طريقة: نشر الاتنين مع بعض (Render) — رابط واحد بس
-----------------------------------------------------------
السيرفر (backend/server.js) أصلاً معمول عشان يعمل serve للـ frontend
كمان من نفس الدومين (app.use(express.static(...'frontend'))). يعني
لو نشرت الـ backend بس، هتلاقي الموقع كله شغال عليه، وده بيحل مشكلة
"الـ index.html جوه فولدر" خالص لأنك مش هتدخل على فرونت إند لوحده.

خطوات Render:
  1. ارفع المشروع كله (بالهيكل ده زي ما هو) على GitHub.
  2. على render.com: New -> Web Service -> اختار الريبو.
  3. Render هيقرأ render.yaml تلقائي (rootDir: backend).
  4. لو مطلوب يدوي: Build Command = npm install
                     Start Command = npm start
  5. بعد الرفع، هتاخد رابط زي:
     https://programming-science.onrender.com
     ده هو رابط الموقع كله (الصفحة الرئيسية + API) من غير أي إعداد تاني.

ملحوظة مهمة: نظام تسجيل الدخول دلوقتي بيحفظ المستخدمين في ملف
backend/data/users.json (مش قاعدة بيانات حقيقية لسه). ده كويس للتجربة،
لكن على Render الفري بلان الملفات بتتمسح كل ما السيرفر يعيد التشغيل
(no persistent disk). يعني المستخدمين هيتمسحوا بين فترة والتانية.
لما يكون عندك وقت، قوللي ننقلها لـ PostgreSQL حقيقي (schema.sql جاهز).

-----------------------------------------------------------
2) لو عايز تنشر الفرونت إند لوحده (Vercel / Netlify)
-----------------------------------------------------------
المشكلة اللي كانت بتحصل: index.html جوه فولدر اسمه frontend، فلو
رفعت المشروع كله من غير ضبط، المنصة هتدور على index.html في الجذر
ومتلاقيهوش.

الحل: لازم تحدد "Root Directory" = frontend في إعدادات المشروع:
  - Vercel: Project Settings -> General -> Root Directory -> اكتب frontend
  - Netlify: Site settings -> Build & deploy -> Base directory -> frontend

بعد كده الموقع هيشتغل عادي والـ index.html هيبقى هو رابط الموقع الرئيسي.

⚠️ في الحالة دي، تسجيل الدخول (login) مش هيلاقي الـ backend لأنه
منشور على دومين تاني. افتح frontend/index.html ودور على السطر ده:
    const API_BASE = '';
وغيّره لرابط الباك إند بتاعك، مثلاً:
    const API_BASE = 'https://programming-science.onrender.com';

-----------------------------------------------------------
3) تشغيل الباك إند على جهازك (تجربة قبل الرفع)
-----------------------------------------------------------
    cd backend
    npm install
    npm start
هيشتغل على http://localhost:4000 وهيعمل serve للفرونت إند من نفسه.

-----------------------------------------------------------
4) تسجيل الدخول — إيه اللي شغال دلوقتي فعليًا
-----------------------------------------------------------
- /api/auth/signup  -> حساب جديد (الاسم + إيميل + كلمة مرور + سن)
- /api/auth/login    -> تسجيل دخول
- /api/auth/me       -> بيانات المستخدم الحالي (محتاج التوكن)
- التوكن بيتخزن في localStorage باسم ps_token بعد الدخول.

ده نسخة أولية (MVP) - زي ما هو موضح جوه server.js. قبل أي إطلاق
حقيقي لعدد كبير من المستخدمين، لازم:
  - ننقل تخزين المستخدمين من JSON file لـ PostgreSQL (schema.sql).
  - نستخدم متغير بيئة (.env) لأي سر بدل ما يتكتب في الكود.

-----------------------------------------------------------
لو أي خطوة ملخبطة أو محتاجة توضيح زيادة، قولّي في المحادثة.
