اتبع الخطوات بالترتيب. كل سكريبت بيفتحلك شاشة نتيجة تلقائي لما يخلص.

1. تثبيت Kali Linux 2. تثبيت الـ IDE + الإضافات 3. شاشة النتيجة

1️⃣ Kali Linux

⚡ تشغيل مباشر جوه المتصفح (بدون تثبيت)

عندك ملف Kali ISO؟ شغّله فورًا جوه المتصفح نفسه — مفيش أي تثبيت على الجهاز ولا إنترنت بعد أول مرة.

📖 دليل سريع قبل ما تبدأ
1
حمّل ملف ISO اختار Live ISO (بيشتغل فوراً) أو Installer ISO (بيثبّت على قرص افتراضي معزول). تحميل Kali Live ↗
2
اضبط الإعدادات اختار الذاكرة (1GB كافية للـLive، 2GB للـInstaller)، نوع المعالج (64-bit في الغالب)، وحجم القرص الافتراضي.
3
اختار الملف وانتظر اضغط "اختار ملف ISO" وانتظر شريط التحميل. بعد "✅ جاهز" النظام بيشتغل في الشاشة أدناه.
4
للـInstaller: انتظر إعادة التشغيل التلقائية بعد انتهاء التثبيت، الموقع هيكمّل الإقلاع من القرص الافتراضي تلقائياً — ما محتاجش تعمل أي حاجة.
5
حفظ الحالة (اختياري) بعد ما النظام يشتغل، اضغط "💾 حفظ الحالة" عشان تقدر ترجعله في أي وقت بدون ما تعمل boot من الأول.
🔒 القرص الافتراضي معزول تماماً في ذاكرة المتصفح — مش بيأثر على أي ملفات حقيقية على جهازك.

🪟 ويندوز (WSL)

حمّل الملف وشغّله كـ Administrator. محتاج ويندوز 10/11 واتصال إنترنت.

wsl --install kali-linux
⬇️ تحميل install.bat

🤖 أندرويد (Termux)

ثبّت تطبيق Termux الأول من F-Droid (مش Google Play). بعدين شغّل السكريبت جواه.

pkg install proot-distro -y && proot-distro install kali
⬇️ تحميل setup.sh

2️⃣ IDE (VS Code) + الإضافات

هيثبّت VS Code ويضيف إضافات البرمجة الأساسية (Python, Pylance, Code Runner, GitLens...) تلقائيًا.

winget install Microsoft.VisualStudioCode
⬇️ تحميل install-ide.bat

📦 مكتبة الإضافات

عايز تزود أو تشيل إضافة؟ افتح الملف وعدّل براحتك — سطر لكل إضافة، والسكريبت بيقرأه تلقائي في المرة الجاية.

📄 extensions.txt

⚠️ ملاحظات

- التثبيت الكامل بياخد مساحة كبيرة نسبيًا (من 1 لـ 3 جيجا تقريبًا) — اتأكد من المساحة المتاحة الأول.
- محتاج اتصال إنترنت وقت التثبيت بس (بعد كده بيشتغل أوفلاين).
- لو مش عايز تثبت حاجة على جهازك، استخدم الوضع الخفيف أو الوسط بدل كده.
